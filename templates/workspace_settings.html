Why This Fix Matters

The original implementation only checked server environment variables, which meant the dashboard could never self-configure Google Workspace.

This settings page removes that bottleneck by letting administrators manage OAuth credentials directly inside the product.

Saved settings are stored server-side and used automatically by Gmail, Drive, and Sheets modules.
