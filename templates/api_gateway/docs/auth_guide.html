Authentication Guide

Authentication Methods

1. API Key Authentication

API Keys are the simplest way to authenticate server-to-server integrations.

Creating an API Key
  1. Go to API Gateway > Auth & Access > API Clients
  2. Create a new API Client or select an existing one
  3. Generate a new credential of type "API Key"
  4. Copy the API key - it won't be shown again
Using the API Key
curl -X GET "https://your-domain.com/api/v1/customers" \ -H "Authorization: Bearer sk_live_abc123..."

2. OAuth 2.0

OAuth is recommended for user-facing applications.

Authorization Code Flow
# Step 1: Redirect user to authorization endpoint GET /oauth/authorize? client_id=YOUR_CLIENT_ID& redirect_uri=YOUR_REDIRECT_URI& response_type=code& scope=read write # Step 2: Exchange code for tokens POST /oauth/token Content-Type: application/x-www-form-urlencoded grant_type=authorization_code& code=AUTH_CODE& client_id=YOUR_CLIENT_ID& client_secret=YOUR_CLIENT_SECRET& redirect_uri=YOUR_REDIRECT_URI # Response { "access_token": "eyJhbG...", "refresh_token": "dGhpcyBpcy...", "expires_in": 3600, "token_type": "Bearer" }

3. JWT Tokens

JWT tokens enable stateless authentication.

# Generate JWT # Use the JWT secret from your client credentials # Include in request Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

Scopes and Permissions

Scopes define what resources your API client can access. Request only the scopes you need.

Available Scopes
Scope Description Danger Level
sales.customers.read Read customer data Low
sales.orders.write Create/update orders Medium
finance.journals.write Create journal entries Critical
