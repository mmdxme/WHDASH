Integration Guides

Getting Started

This guide will help you integrate with the MMDx API.

1. Authentication

All API requests require authentication. Use one of the following methods:

  • API Key - For server-to-server integrations
  • OAuth 2.0 - For user-facing applications
  • JWT Token - For stateless authentication
2. Making Your First Request
GET /api/v1/customers Authorization: Bearer YOUR_API_KEY Response: { "data": [...], "meta": { "page": 1, "per_page": 20, "total": 150 } }
3. Pagination

List endpoints support pagination using query parameters:

GET /api/v1/customers?page=2&per_page=50
4. Filtering

Use query parameters to filter results:

GET /api/v1/customers?status=active&city=Dubai
5. Error Handling

All errors follow a consistent format:

{ "error": { "code": "AUTH_001", "message": "Invalid API key", "details": {} } }

Webhooks Guide

Webhooks allow you to receive real-time notifications when events occur.

Setting Up Webhooks
  1. Go to Webhooks > Subscriptions
  2. Click "New Subscription"
  3. Enter your endpoint URL
  4. Select the events you want to receive
  5. Configure authentication if needed
Webhook Payload
{ "event": "order.created", "timestamp": "2026-04-07T12:00:00Z", "data": { "order_id": "ORD-2026-00001", "customer_id": "CUST-001", "total": 1500.00 }, "delivery_id": "dlv_abc123" }
