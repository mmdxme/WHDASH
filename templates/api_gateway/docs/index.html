Getting Started

Quick Start

  1. Create an API Client in the API Clients section
  2. Generate API credentials (API Key or OAuth)
  3. Configure your integration's allowed scopes
  4. Start making API requests using your credentials

Base URL

https://your-domain.com/api/v1

Authentication

Include your API key in the request header:

Authorization: Bearer YOUR_API_KEY

Rate Limiting

All API requests are rate-limited based on your client's profile. Check the rate limit headers in responses:

  • X-RateLimit-Limit - Maximum requests allowed
  • X-RateLimit-Remaining - Requests remaining in window
  • X-RateLimit-Reset - Time when the limit resets
