## RTL Considerations

### Layout Adjustments
- All flex/grid directions flip in RTL mode
- Icon positions adjust automatically
- Table column alignment reverses
- Form labels align right

### Currency Display
- Currency symbol position varies by locale
- Number formatting uses locale-specific separators
- Date formats follow locale conventions

### Mixed Content
- Arabic/Persian text displays RTL
- English text within Arabic contexts maintains LTR
- Numbers and codes remain LTR within RTL text
