2. ROOT CAUSE CATEGORIES FOUND
================================================================================

CATEGORY D: Endpoint naming mismatch between templates and routes
- Templates use 'module_endpoint' (e.g., 'project_list')
- Routes register with blueprint prefix 'module.module_endpoint' (e.g., 'project.project_list')
- This causes Flask url_for() to fail with BuildError

CATEGORY B: Blueprint registration but routes not exposed to url_for
- feedback_bp is registered but some templates reference it differently

CATEGORY F: Hardcoded URL placeholder links (non-functional but not 404)
- Issue Tracker menu items in menu_macros.html use href="#" as placeholders
