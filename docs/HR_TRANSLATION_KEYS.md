## 1. Overview

This document lists all translation keys used in the HR module across all 8 supported languages:
- English (en) - Default
- Arabic (ar) - RTL
- Persian/Farsi (fa) - RTL
- Russian (ru)
- Hindi (hi)
- Spanish (es)
- Chinese (zh)
- German (de)
