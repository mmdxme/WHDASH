# File Management Translation Keys

## Overview

This document lists all translation keys used in the File Management module. All keys must be translated into all 8 supported languages: English (en), Persian (fa), Arabic (ar), Russian (ru), Hindi (hi), Chinese (zh), Spanish (es), and German (de).

## Translation Structure

Translations are defined in `translations.py` under the `TRANSLATIONS` dictionary. Each language has its own section with key-value pairs.

## RTL Support

### Direction Detection

```jinja2
<html dir="{{ 'rtl' if current_lang in ['ar', 'fa'] else 'ltr' }}">
```

### Common RTL Patterns

| English | Persian (RTL) | Arabic (RTL) |
|---------|---------------|--------------|
| margin-left | margin-right | margin-right |
| padding-right | padding-left | padding-left |
| text-align: left | text-align: right | text-align: right |
| flex-direction: row | flex-direction: row-reverse | flex-direction: row-reverse |

### Font Support

RTL languages require proper font stacking:
```css
font-family: 'Segoe UI', 'Tahoma', 'Arial', sans-serif;
```
