# Quality Management Translation Keys Guide

## Overview

The Quality Management module includes comprehensive translations for all 8 supported languages:
- English (en)
- Persian/Farsi (fa)
- Arabic (ar)
- Russian (ru)
- Chinese (zh)
- Spanish (es)
- Hindi (hi)
- German (de)

## Translation Key Structure

All quality translation keys are prefixed with relevant module indicators:
- `quality_*` - Quality module main terms
- `inspection*` - Inspection-related terms
- `ncr_*` - NCR-related terms
- `capa_*` - CAPA-related terms
- `audit*` - Audit-related terms

## RTL Support

The translations support RTL languages (Persian and Arabic) with:
- Automatic text direction detection
- Mirrored layouts
- RTL-safe icons and navigation
- Bidirectional text support
- Proper number formatting

## Implementation

Translations are loaded from `translations.py` and applied via the `get_translation()` helper or direct key lookup in templates using Jinja2:

```html
<!-- Template usage -->
<h1>{{ translations.quality_dashboard }}</h1>
<span>{{ translations.inspection }}</span>
```

For dynamic translations in JavaScript:
```javascript
// Get translation via API or preloaded data
const label = translationsData['quality_dashboard'];
```
