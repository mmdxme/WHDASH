================================================================================
                           1. EXECUTIVE SUMMARY
================================================================================

MMDx (Multi-Module Dashboard X) is a comprehensive Flask-based Enterprise
Resource Planning (ERP) and Warehouse Management System (WMS) built with
Python/Flask. It serves as a unified command center for managing multiple
business functions across inventory, procurement, finance, HR, CRM,
logistics, quality management, and more.

The system is production-ready with 417 Python files, 1,943 HTML templates,
49 route modules, 43 model modules, and supports 8 languages (English,
Persian, Arabic, Russian, Hindi, Spanish, Chinese, German).

KEY HIGHLIGHTS:
- Multi-tenant architecture with 4 subsidiary support (Holding, SDAD, AFRA,
  Carmania)
- 40+ independent business modules
- SQLite database with PostgreSQL-ready architecture
- Role-Based Access Control (RBAC) with granular permissions
- Web push notifications, Celery background jobs
- Google Workspace integration
- SAP BTP integration capability
- Full audit logging and compliance features

                  5. TECHNICAL ARCHITECTURE ANALYSIS
================================================================================

5.1 APPLICATION LAYER
---------------------
- Framework: Flask 3.1.3
- WSGI Server: Gunicorn (production), Flask dev server (development)
- Template Engine: Jinja2 (1934 templates)
- Session Management: Flask sessions with SQLite/Redis
- Cache: Redis-ready architecture

5.2 DATABASE LAYER
-----------------
- Primary: SQLite with WAL mode
- Architecture: PostgreSQL-ready (via DB_ENGINE config)
- Schema: Centralized in sqlite_schema.sql
- Tables: 100+ across all modules
- Features: Connection pooling, query helpers

5.3 AUTHENTICATION & SECURITY
------------------------------
- RBAC: Unified permission system with module/resource/action hierarchy
- Password: Werkzeug password hashing
- Sessions: Secure cookie-based sessions
- Audit: Comprehensive logging
- SSO: Google Workspace integration
- Web Push: VAPID-based notifications

5.4 EXPORT/REPORTING
--------------------
Formats Supported:
- CSV (comma-separated)

- PDF (via reportlab, weasyprint)
- Word (DOCX via python-docx)

- Barcode (QR code via qrcode)
