## RTL/LTR Support

### Implementation
- HTML `dir="auto"` attribute for bidirectional text
- CSS `unicode-bidi: plaintext` for message content
- Direction detection for mixed RTL/LTR content

### Key Classes
```css
.bidi-text {
    unicode-bidi: plaintext;
    direction: auto;
    text-align: start;
}

.message-content {
    unicode-bidi: plaintext;
    direction: auto;
}
```
