## Translation File Structure

Translations are stored in `translations.py` as a dictionary with language codes as keys:
- `en` - English
- `ar` - Arabic
- `fa` - Persian/Farsi
- `de` - German
- `hi` - Hindi
- `ru` - Russian
- `zh` - Chinese
- `tr` - Turkish

Each language has a dictionary of key-value pairs. The module uses the `t()` function to translate keys:
```python
t('key_name', lang)  # Returns translated string for the given language
```

## RTL Support

The module supports RTL (Right-to-Left) languages (Arabic, Persian). The `is_rtl(lang)` function checks if a language requires RTL text direction. The HTML `dir` attribute is set accordingly in the base template:

```html
<html lang="{{ lang }}" dir="{{ 'rtl' if is_rtl(lang) else 'ltr' }}">
```
